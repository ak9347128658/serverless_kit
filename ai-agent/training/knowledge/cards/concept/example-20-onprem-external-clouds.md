# Example: 20-onprem-external-clouds

This directory is one of the examples that tests/test_examples.py packages and runs locally because it contains pskit.yml. Files here include README.md, pskit.yml, requirements.txt. Comments in pskit.yml: One on-premises host watching queues and buckets that live in other clouds. Every secret is given as `<name>_env: VARIABLE`: the host reads it from its own environment when it starts, so no key is written to pskit_host.json or Terraform state. A variable that is missing stops the host with an error naming it. # 20 · On premises, watching other clouds

A single on-prem host consumes queues and watches buckets that live in AWS, Azure, Google Cloud, Alibaba Cloud, Cloudflare and a self-hosted MinIO. The handlers are ordinary pskit handlers. Retries (`BatchResult`), dead-lettering, logs, stats and the dashboard work the same as with the built-in queues. | Resource | Driver | Service | | --- | --- | --- | | `aws-jobs` | `sqs` | Amazon SQS | | `azure-jobs` | `azure_queue` | Azure Storage Queue | | `gcp-jobs` | `pubsub` | Google Pub/Sub (pull subscription) | | `alibaba-jobs` | `mns` | Alibaba Cloud MNS | | `cf-jobs` | `cloudflare_queue` | Cloudflare Queues | | `aws-media` | `aws` | Amazon S3 | | `azure-media` | `azure_blob` | Azure Blob Storage | | `gcp-media` | `gcs` | Google Cloud Storage | | `r2-media` | `r2` | Cloudflare R2 | | `minio-media` | `minio` | MinIO / Ceph | `pskit.yml` also lists the presets for Alibaba OSS, Tencent COS, Huawei OBS, Oracle Object Storage, IBM COS and DigitalOcean Spaces. For brokers without a built-in driver (RabbitMQ, Kafka, IBM MQ, OCI Queue, TDMQ, DMS), see `19-custom-drivers`.
