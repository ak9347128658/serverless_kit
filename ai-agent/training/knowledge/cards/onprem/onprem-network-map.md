# Network and firewall rules (on premises)

Which machine must accept **inbound connections, and which must be allowed **outbound**, at each step: saving servers, deploying, running, clusters, joining servers, load balancers, function groups on several servers, and resources / triggers. Ports in *italics* are defaults you can change. **You do not have to work these out by hand.** Every step prints the rules it just made necessary, with your servers' names and addresses and `ufw` commands: `pskit cluster create`, `pskit cluster join`, `pskit deploy` (one server, function groups or a cluster), `pskit lb create`, `pskit lb attach`, `pskit cluster balancer set`, a project's `balancer` route, and `pskit resources onprem create`. `pskit firewall` lists everything the project needs now, per server (`--server edge2`, `--json`); the studio shows the same in a **Firewall** panel (Deploy, cluster and load balancer pages) and in each job's output: **Legend:** 🟥 **required** (it does not work without it) · 🟨 **needed for that feature** · 🟩 optional (convenience; pskit falls back to an SSH tunnel)
## The machines |

Role | What it is | |---|---| | **Admin machine** | where you run `pskit` / the studio (your laptop, a CI runner) | | **Function server** | runs a function host (one machine, or one placement group) | | **Cluster master / worker** | servers of a scaling cluster (Swarm, k3s, Nomad) | | **Load balancer server** | runs OpenResty for `pskit lb` or `pskit cluster balancer` | | **Resource server** | runs an on-prem service (Redis, Postgres, MinIO, SMTP, ...) | | **Users** | browsers, apps, other systems calling your functions | `FN_PORT` below is `provider.options.port` (*8080*), or a placement group's own `port`. ---
## 1. Always: the admin machine reaches every server over SSH | | From | To | Port

| Why | |---|---|---|---|---| | 🟥 | Admin machine | **every** saved server (function, cluster, load balancer, resource) | **TCP *22*** (the server's SSH port) | scripts, copying the release / image (`scp`), logs, tests, status | | 🟥 | every server, **outbound** | Internet **TCP 443 / 80** | — | first time only: install Docker (`get.docker.com`, distro repos), pull images (Docker Hub), k3s (`get.k3s.io`, GitHub), Nomad (`releases.hashicorp.com`) | | 🟥 | Admin machine, **outbound** | Internet **TCP 443** | — | PyPI / npm while packaging; `python: bundle` / `node: bundle` downloads; Docker base images for `method: docker` | Servers with no Internet: preinstall Docker (and k3s / Nomad), and load the images yourself (`docker load`). pskit copies the function image itself over SSH, so no registry is needed.
