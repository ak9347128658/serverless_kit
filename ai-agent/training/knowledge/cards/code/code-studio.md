# Code: Studio server

The deploy pipeline in the architecture doc is pskit.yml, then the config loader, the schema, the project, provider validate, the packaging builder, provider render to main.tf.json, the Terraform runner, deployment.json, and the dashboard. The runtime path is platform, shim, adapter, dispatch.execute, handler. runtime/ is stdlib-only and stays on Python 3.9. Terraform is built as Python dicts. Zip artifacts are byte-reproducible.

`src/py_serverless_kit/studio/__init__.py`: ``pskit studio``: a local web app that builds pskit projects without hand-written YAML. `src/py_serverless_kit/studio/devenv.py`: The project's local environment: a ``.venv`` with ``requirements.txt`` (Python) or ``npm install`` (Node.js). `src/py_serverless_kit/studio/discover.py`: ``GET /api/discover``: list existing queues, buckets, topics and workflows to pick from. `src/py_serverless_kit/studio/files.py`: Project file access for the studio's code editor, confined to the project root. `src/py_serverless_kit/studio/guides.py`: The step-by-step resource guides (``docs/resource-guides``) for the studio. `src/py_serverless_kit/studio/jobs.py`: Run pskit commands (validate, deploy, ...) for the studio and stream their output. `src/py_serverless_kit/studio/meta.py`: ``GET /api/meta``: the catalog that drives every studio form. `src/py_serverless_kit/studio/node_stubs.py`: Handler stubs for Node.js services (TypeScript, ESM or CommonJS JavaScript). `src/py_serverless_kit/studio/project.py`: Read, validate and save ``pskit.yml`` for the studio. `src/py_serverless_kit/studio/server.py`: ``pskit studio``: build a project in the browser instead of writing YAML by hand. `src/py_serverless_kit/studio/system.py`: Studio helpers that reach outside the project: a file picker, setup checks and deployed logs. `src/py_serverless_kit/studio/vscode.py`: Full VS Code in the browser: code-server in Docker, pulled on first use.
