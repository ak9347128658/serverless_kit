# Code: On-premises resource drivers

The deploy pipeline in the architecture doc is pskit.yml, then the config loader, the schema, the project, provider validate, the packaging builder, provider render to main.tf.json, the Terraform runner, deployment.json, and the dashboard. The runtime path is platform, shim, adapter, dispatch.execute, handler. runtime/ is stdlib-only and stays on Python 3.9. Terraform is built as Python dicts. Zip artifacts are byte-reproducible.

`src/py_serverless_kit/runtime/drivers/__init__.py`: External backends the on-premises host can use for queues and storage. `src/py_serverless_kit/runtime/drivers/_aws.py`: AWS Signature Version 4 and credential lookup, shared by the ``s3`` and ``sqs`` drivers. `src/py_serverless_kit/runtime/drivers/_http.py`: Small HTTP helper shared by the REST-based drivers (standard library only). `src/py_serverless_kit/runtime/drivers/azure.py`: Azure Storage Queue and Blob drivers (REST, standard library only). `src/py_serverless_kit/runtime/drivers/cloudflare.py`: Cloudflare Queues driver through the HTTP pull consumer API (standard library only). `src/py_serverless_kit/runtime/drivers/gcp.py`: Google Cloud Pub/Sub (pull) and Cloud Storage drivers (REST, standard library only). `src/py_serverless_kit/runtime/drivers/mns.py`: Alibaba Cloud MNS (Message Service) queue driver (REST + XML, standard library only). `src/py_serverless_kit/runtime/drivers/probe.py`: Check that a database / cache / custom service answers (standard library only). `src/py_serverless_kit/runtime/drivers/pskit_host.py`: A built-in queue of another pskit on-premises host (standard library only). `src/py_serverless_kit/runtime/drivers/redis.py`: Redis-backed queue for the on-premises host (standard library only). `src/py_serverless_kit/runtime/drivers/redis_stream.py`: A Redis / Valkey stream with a consumer group as an on-prem queue (standard library only). `src/py_serverless_kit/runtime/drivers/s3.py`: S3-compatible object storage for the on-premises host (standard library only). `src/py_serverless_kit/runtime/drivers/sqs.py`: AWS SQS queue driver (JSON protocol, SigV4, standard library only).
