# Code: Provider plugins

The deploy pipeline in the architecture doc is pskit.yml, then the config loader, the schema, the project, provider validate, the packaging builder, provider render to main.tf.json, the Terraform runner, deployment.json, and the dashboard. The runtime path is platform, shim, adapter, dispatch.execute, handler. runtime/ is stdlib-only and stays on Python 3.9. Terraform is built as Python dicts. Zip artifacts are byte-reproducible.

src/py_serverless_kit/providers/__init__.py has no module docstring. `src/py_serverless_kit/providers/alibaba.py`: Alibaba Cloud: Function Compute 3.0 + HTTP / timer / OSS / MNS-topic triggers. `src/py_serverless_kit/providers/aws.py`: AWS: Lambda + API Gateway HTTP API + EventBridge Scheduler + SQS + S3 + SNS + Step Functions. `src/py_serverless_kit/providers/azure.py`: Azure: Linux Function App (Consumption plan, Python v2 / Node.js v4 programming model). `src/py_serverless_kit/providers/base.py`: Provider plug-in contract. `src/py_serverless_kit/providers/cloudflare.py`: Cloudflare Workers, one Worker script per function, in Python (Pyodide) or JavaScript. `src/py_serverless_kit/providers/digitalocean.py`: DigitalOcean Functions. `src/py_serverless_kit/providers/gcp.py`: GCP: Cloud Functions (2nd gen) + Cloud Scheduler + Pub/Sub + Cloud Storage + Cloud Workflows. `src/py_serverless_kit/providers/huawei.py`: Huawei Cloud: FunctionGraph + dedicated API Gateway + timer / OBS / SMN triggers. `src/py_serverless_kit/providers/ibm.py`: IBM Cloud: Code Engine functions (HTTP endpoints). `src/py_serverless_kit/providers/onprem.py`: On-premises provider. `src/py_serverless_kit/providers/onprem_catalog.py`: Data catalog of the on-premises resource drivers, used by ``pskit studio`` forms. `src/py_serverless_kit/providers/onprem_remote.py`: Laptop-side apply/destroy for an on-premises host. `src/py_serverless_kit/providers/onprem_spec.py`: Parse and validate ``provider.options.deploy`` for the on-premises provider. `src/py_serverless_kit/providers/oracle.py`: Oracle Cloud Infrastructure: OCI Functions (container images) + API Gateway + Events. `src/py_serverless_kit/providers/regions.py`: Public regions per built-in provider, for pickers (studio) and help text. `src/py_serverless_kit/providers/registry.py`: Provider registry. Third-party providers can register through the `src/py_serverless_kit/providers/schedule.py`: Convert the portable schedule syntax into each provider's dialect. `src/py_serverless_kit/providers/tencent.py`: Tencent Cloud: SCF + API Gateway + timer / COS triggers. `src/py_serverless_kit/providers/terraform_doc.py`: Builder for Terraform JSON configuration (``main.tf.json``).
