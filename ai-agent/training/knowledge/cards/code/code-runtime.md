# Code: Portable runtime

The deploy pipeline in the architecture doc is pskit.yml, then the config loader, the schema, the project, provider validate, the packaging builder, provider render to main.tf.json, the Terraform runner, deployment.json, and the dashboard. The runtime path is platform, shim, adapter, dispatch.execute, handler. runtime/ is stdlib-only and stays on Python 3.9. Terraform is built as Python dicts. Zip artifacts are byte-reproducible.

`src/py_serverless_kit/runtime/__init__.py`: Portable function runtime. `src/py_serverless_kit/runtime/batch.py`: Partial batch failure reporting for queue / topic / storage events. `src/py_serverless_kit/runtime/context.py`: Provider-neutral invocation context. `src/py_serverless_kit/runtime/cron.py`: 5-field cron and rate schedules for the on-premises host. `src/py_serverless_kit/runtime/dispatch.py`: Calls the user's handler with a normalized event and normalizes the result. `src/py_serverless_kit/runtime/errors.py`: Exceptions a handler can raise to produce a well-formed HTTP error response. `src/py_serverless_kit/runtime/event.py`: Provider-neutral event model. `src/py_serverless_kit/runtime/executions.py`: Tracked workflow executions for the embedded engine. `src/py_serverless_kit/runtime/hostlog.py`: Log capture for the on-premises host. `src/py_serverless_kit/runtime/invoke.py`: Portable function-to-function invocation. `src/py_serverless_kit/runtime/log.py`: Structured JSON logging that every provider's log pipeline can ingest. `src/py_serverless_kit/runtime/manifest.py`: Reads ``pskit_manifest.json`` - the per-bundle description of every function. `src/py_serverless_kit/runtime/node_worker.py`: Drive Node.js functions from Python through ``pskit_runtime/worker.js``. `src/py_serverless_kit/runtime/onprem_host.py`: On-premises host: one process for HTTP, schedules, queues, storage and topics. `src/py_serverless_kit/runtime/peers.py`: Function groups on other servers (on-prem ``provider.options.placement``): reach them over HTTP. `src/py_serverless_kit/runtime/resources.py`: Read the ``resources:`` bindings of the current function. `src/py_serverless_kit/runtime/response.py`: Provider-neutral HTTP response model. `src/py_serverless_kit/runtime/routing.py`: Tiny route matcher used where the provider has no API gateway in front of the `src/py_serverless_kit/runtime/secrets.py`: Read (and write) secrets from handlers with one call on every provider. `src/py_serverless_kit/runtime/workflow.py`: Embedded workflow (state machine) engine.
