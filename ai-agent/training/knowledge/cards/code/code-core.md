# Code: Core deploy and describe

The deploy pipeline in the architecture doc is pskit.yml, then the config loader, the schema, the project, provider validate, the packaging builder, provider render to main.tf.json, the Terraform runner, deployment.json, and the dashboard. The runtime path is platform, shim, adapter, dispatch.execute, handler. runtime/ is stdlib-only and stays on Python 3.9. Terraform is built as Python dicts. Zip artifacts are byte-reproducible.

src/py_serverless_kit/core/__init__.py has no module docstring. `src/py_serverless_kit/core/client_examples.py`: Complete programs that use one on-prem resource through the pskit host (pskit client). `src/py_serverless_kit/core/client_guide.py`: How to call a deployed on-prem host from any program: the pskit client (Python, Node.js) and HTTP. `src/py_serverless_kit/core/cloud_logs.py`: Read, list and delete the logs of a deployment, whatever cloud it runs on. `src/py_serverless_kit/core/deployer.py`: High level package / deploy / remove orchestration used by the CLI. `src/py_serverless_kit/core/describe.py`: Builds the deployment record that powers ``pskit info`` and the dashboard. `src/py_serverless_kit/core/executions.py`: List, inspect, start and cancel workflow executions of a deployment. `src/py_serverless_kit/core/function_split.py`: Move a function that shares a code file with others into its own sub-project folder. `src/py_serverless_kit/core/project.py`: A loaded project: config + provider + working directory, ready to build/deploy. `src/py_serverless_kit/core/resource_code.py`: Ready-to-paste Python and Node.js handler code for each resource. `src/py_serverless_kit/core/resource_usage.py`: End-to-end "how to use this resource" guide, for one resource of the current project. `src/py_serverless_kit/core/retain.py`: ``pskit remove --keep-resources``: destroy functions and triggers, keep the data. `src/py_serverless_kit/core/settings_bundle.py`: Move a project's local settings to another machine: one passphrase-encrypted file. `src/py_serverless_kit/core/setup_check.py`: Check what a provider needs on this machine, and explain how to fix what's missing. `src/py_serverless_kit/core/testing.py`: Test functions with real events: what to send, how, and sending it.
