# Code: On-premises service modules

The deploy pipeline in the architecture doc is pskit.yml, then the config loader, the schema, the project, provider validate, the packaging builder, provider render to main.tf.json, the Terraform runner, deployment.json, and the dashboard. The runtime path is platform, shim, adapter, dispatch.execute, handler. runtime/ is stdlib-only and stays on Python 3.9. Terraform is built as Python dicts. Zip artifacts are byte-reproducible.

`src/py_serverless_kit/core/onprem_apps.py`: More one-click on-prem services: AWS emulators, secret managers, monitoring, identity, search, automation, tools. `src/py_serverless_kit/core/onprem_browser.py`: pskit's own web UI for on-prem services whose native UI is missing or limited. `src/py_serverless_kit/core/onprem_clients.py`: Use an on-prem resource from *any* program: a script, a web app, a cron job, another service. `src/py_serverless_kit/core/onprem_console.py`: A console for one-click services, in the studio and the CLI: type a command, see its output. `src/py_serverless_kit/core/onprem_monitor.py`: Live monitoring, alerts and data import for on-prem databases (and the CPU / memory of any service container). `src/py_serverless_kit/core/onprem_replication.py`: Replicated databases: one primary that takes the writes, read replicas on other servers, and an optional load `src/py_serverless_kit/core/onprem_runtimes.py`: Software pskit installs on an SSH server: language runtimes, web servers and tools. `src/py_serverless_kit/core/onprem_s3.py`: The ``s3`` / ``s3-node`` on-prem services: pskit's Amazon S3 compatible server. `src/py_serverless_kit/core/onprem_secretsmanager.py`: The ``secretsmanager`` / ``secretsmanager-node`` on-prem services: pskit's AWS Secrets Manager compatible server. `src/py_serverless_kit/core/onprem_servers.py`: Saved SSH servers: name a machine once, then create services, install software, open consoles and deploy to it. `src/py_serverless_kit/core/onprem_services.py`: Create, inspect, back up and remove the services on-premises functions use. `src/py_serverless_kit/core/onprem_smtp.py`: The ``smtp`` on-prem service: a Node.js SMTP server that turns received mail into ``smtp`` events. `src/py_serverless_kit/core/onprem_terminal.py`: A full terminal in the browser (ttyd in Docker on this machine): SSH to a server, or a shell / client inside a
