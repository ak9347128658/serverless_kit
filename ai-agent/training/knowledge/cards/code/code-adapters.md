# Code: Runtime adapters

The deploy pipeline in the architecture doc is pskit.yml, then the config loader, the schema, the project, provider validate, the packaging builder, provider render to main.tf.json, the Terraform runner, deployment.json, and the dashboard. The runtime path is platform, shim, adapter, dispatch.execute, handler. runtime/ is stdlib-only and stays on Python 3.9. Terraform is built as Python dicts. Zip artifacts are byte-reproducible.

`src/py_serverless_kit/runtime/adapters/__init__.py`: Per-provider translation between native payloads and the portable model. `src/py_serverless_kit/runtime/adapters/_httpfn.py`: Shared logic for providers where *every* invocation arrives as an HTTP-ish `src/py_serverless_kit/runtime/adapters/alibaba.py`: Alibaba Cloud Function Compute 3.0 adapter. `src/py_serverless_kit/runtime/adapters/aws.py`: AWS Lambda adapter. `src/py_serverless_kit/runtime/adapters/azure.py`: Azure Functions (Python v2 programming model) adapter. `src/py_serverless_kit/runtime/adapters/base.py`: Helpers shared by all adapters. `src/py_serverless_kit/runtime/adapters/cloudflare.py`: Cloudflare Python Workers adapter (Pyodide). `src/py_serverless_kit/runtime/adapters/digitalocean.py`: DigitalOcean Functions adapter (``main(event, context)``). `src/py_serverless_kit/runtime/adapters/gcp.py`: Google Cloud Functions (2nd gen) adapter. `src/py_serverless_kit/runtime/adapters/huawei.py`: Huawei Cloud FunctionGraph adapter. `src/py_serverless_kit/runtime/adapters/ibm.py`: IBM Cloud Code Engine functions adapter. `src/py_serverless_kit/runtime/adapters/onprem.py`: On-premises adapter. `src/py_serverless_kit/runtime/adapters/oracle.py`: Oracle Cloud (OCI) Functions adapter, built on the Fn Project Python FDK. `src/py_serverless_kit/runtime/adapters/tencent.py`: Tencent Cloud SCF adapter.

Studio pages and the pskit command line both call this package. pskit validate loads the schema before a provider renders main.tf.json. The runtime that is copied into a bundle stays on the standard library and on Python 3.9. Generated zip files sort their entries and use fixed timestamps so unchanged inputs hash the same way. Handlers stay the same across providers. Provider-specific behavior belongs in options and in the provider module.
